## 📋 **Project Overview**

This is a comprehensive handoff package for transitioning the **Claude Crew System** project to Cursor. The system represents a complete Starfleet crew implementation using Claude AI agents with specialized capabilities, n8n workflow integration, and a sophisticated memory system.

- **Counselor Troi**: Psychological Analysis & Emotional Intelligence

- **Claude Agent System**: Python-based AI agents with specialized capabilities

- **Memory System**: Supabase-based persistent memory and learning
