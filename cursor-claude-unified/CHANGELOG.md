# Changelog

All notable changes to the Cursor-Claude Autonomous AI Collaboration extension will be documented in this file.

## [2.0.0] - 2025-08-30

### 🚀 **MAJOR UPGRADE: Autonomous AI Collaboration System**

#### **Added**
- **🤖 Autonomous Collaboration Engine**: Complete AI autonomy where LLMs decide everything without user input
- **🎯 Intelligent Task Analysis**: System automatically analyzes tasks and assigns optimal AI roles
- **🔄 Seamless AI Coordination**: Claude and Cursor work together automatically based on task requirements
- **🔍 Autonomous Review Process**: AIs validate and improve each other's work automatically
- **🎯 Integrated Results**: Best of both AIs automatically combined into seamless solutions

#### **Changed**
- **Version**: Upgraded from 1.0.0 to 2.0.0
- **Display Name**: Changed from "Cursor-Claude Unified Chat" to "Cursor-Claude Autonomous AI Collaboration"
- **Description**: Updated to reflect autonomous collaboration capabilities
- **User Experience**: Eliminated all user choice prompts - completely frictionless interaction
- **Command Titles**: Updated to reflect autonomous system (e.g., "Start Autonomous AI Collaboration")

#### **Removed**
- **User Choice System**: No more manual AI selection required
- **Democratic Selection Prompts**: AIs now decide everything automatically
- **Manual Coordination**: User no longer needs to manage AI collaboration

#### **Technical Improvements**
- **New Service**: `AutonomousCollaborationEngine` for intelligent AI coordination
- **Extended Interfaces**: New type definitions for autonomous collaboration
- **Enhanced Webview**: Updated chat interface for autonomous collaboration
- **Improved Context**: Better file and workspace awareness for AI decision making

#### **Breaking Changes**
- **Major Version Bump**: From 1.0.0 to 2.0.0 indicates significant architectural changes
- **API Changes**: New autonomous collaboration interfaces and methods
- **User Flow**: Complete elimination of user choice in AI selection process

## [1.0.0] - 2025-08-30

### 🎉 **Initial Release: Democratic AI Collaboration**

#### **Added**
- **Democratic AI Selection**: System for choosing between Claude and Cursor based on task requirements
- **Unified Chat Interface**: Integrated chat system for both AIs
- **Cross-Reference Engine**: AI collaboration and reference system
- **Confidence Scoring**: AI selection based on confidence levels
- **Cost Management**: Budget control for AI API usage

#### **Features**
- **User Choice System**: Manual selection between Claude and Cursor
- **Task Classification**: Automatic task type detection
- **Collaboration Modes**: Different AI collaboration strategies
- **Context Awareness**: File and workspace context integration
- **Export Functionality**: Conversation export capabilities

## Upgrade Notes

### **From 1.0.0 to 2.0.0**
This is a **major version upgrade** that fundamentally changes how the extension works:

1. **Backup**: Save any important conversations before upgrading
2. **Uninstall**: Remove the old 1.0.0 version
3. **Install**: Install the new 2.0.0 version
4. **Test**: Verify autonomous collaboration is working

### **Compatibility**
- **VS Code**: Requires VS Code 1.80.0 or higher
- **Cursor AI**: Fully compatible (built on VS Code)
- **Node.js**: Requires Node.js 16.x or higher

### **Migration Guide**
- **Settings**: Most settings remain compatible
- **Commands**: Command names updated to reflect autonomous system
- **UI**: Chat interface updated for autonomous collaboration
- **Behavior**: Complete change from user-choice to autonomous system
